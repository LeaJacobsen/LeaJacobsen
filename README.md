I'm an IT-Technology student at Zealand (EASJ) in Denmark. I like making systems actually *run* — from Docker stacks deployed to Azure with Terraform, to Raspberry Pis, Arduinos and PCBs I can hold in my hand.

## Projects

* [**LEMP stack on Azure**](https://github.com/LeaJacobsen/lempstack): Nginx, PHP, MariaDB and Varnish in Docker, deployed with Terraform, monitored with Prometheus and Grafana, plus an MQTT broker for IoT sensors
* [**Line-following robot**](https://github.com/LeaJacobsen/RaspberryPi-Line-Following-RoboRover): a Raspberry Pi robot in Python that follows a black line using two IR sensors (group project, work in progress)
* **A personal safety alarm PCB**: designed in KiCad with an ESP32 and a LoRa module (not published yet)
* [**WillisRover**](https://github.com/LeaJacobsen/willisrover): a garden rover that measures soil moisture and climate and shows it on a map (2nd semester exam project, group)
* [**Playwright tests of zealand.dk**](https://github.com/LeaJacobsen/playwright-zealand-tests): automated browser tests in three browsers, run by GitHub Actions
* [**Library Management System**](https://github.com/LeaJacobsen/library-management-system): a Python OOP command-line app with SQLite and unit tests
* [**Beehive datalogger**](https://github.com/LeaJacobsen/beehive-datalogger): Arduino logger measuring temperature, humidity and light in and around a beehive (1st semester exam project, group)
* [**Arduino theft alarm**](https://github.com/LeaJacobsen/arduino-theft-alarm): motion-triggered alarm with keypad code, LCD and buzzer (one of my very first projects)
